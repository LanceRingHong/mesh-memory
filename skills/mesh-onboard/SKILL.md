# mesh-onboard

## 何时用

- 用户是新手、记忆库为空或很乱；
- 用户说“不知道该怎么用 / 帮我搭一套 / 从哪开始”。

## 流程

### 0. 预检

- 跑一次 `mesh_status`，确认记忆目录、设备名、计数；
- 已有内容多 → 这是“重构”，先盘点现状，不要直接建新结构。

### 1. 访谈（一次只问一个问题）

需要知道：

1. 想跟踪哪些领域（任务/笔记/人脉/研究/财务/流程/健康/资产）；
2. 使用频率（每天几条 vs 每周几条）；
3. 每个领域举一个**真实例子**；
4. 以前用过什么、为什么失败。

建议先做 2–3 个领域，不要一次铺 6 个。

### 2. 蓝图

调 `mesh_memory_onboard`（preview）生成建议，然后用自己的话补全：

- 目录/分类（facts/decisions/projects/notes）；
- 每类记什么、标题怎么写；
- 哪 1–3 条设 baseline；
- 前 2–3 条真实笔记写什么。

把蓝图讲给用户听，**得到明确“可以”再进入下一步**。

### 3. 落地

- `mesh_memory_onboard` 加 `apply:true` + `confirm:true` 写蓝图笔记；
- 按用户给的例子写 2–3 条真实记忆（不要占位数据）；
- 可选：把稳定规则写进 `AGENTS.shared.md`（先预览 diff，再 confirm）。

### 4. 教学

带用户做一遍：捕获 → 搜索 → 更新 → 标记失效。

### 5. 维护节奏

- 每天/每周 `mesh-reflect`；
- 每月 `mesh-doctor` + `mesh-curate`；
- 结构不顺手时改规则，不要默默绕过。
